## Introduction

This repository contains the solutions for Lab 03 of the Programming Fundamentals course.
The lab focuses on understanding C's basic data types, format specifiers, standard
input/output functions, escape sequences, and precision handling for floating-point
values. It also demonstrates the use of Git and GitHub for version control, including
branching, committing, and pull requests.

## Objectives

1. Understand and use different C data types (`int`, `float`, `double`, `char`, `bool`, `void`).
2. Learn to use format specifiers correctly with `printf()` and `scanf()`.
3. Practice character input/output using `getchar()` and `putchar()`.
4. Learn safe string input/output techniques using `fgets()` and `puts()`.
5. Understand and apply escape sequences to format program output.
6. Learn to control floating-point precision in output.
7. Practice Git workflow: branching, committing, and pull requests on GitHub.

## C Topics Covered in Lab 03

- Data types (`int`, `float`, `double`, `char`, `bool`, `void`)
- Format specifiers (`%d`, `%u`, `%o`, `%x`, `%X`, `%f`, `%e`, `%c`, `%s`, `%ld`)
- Input/output functions (`scanf`, `printf`, `getchar`, `putchar`, `fgets`, `puts`)
- Escape sequences (`\n`, `\t`, `\\`, `\'`, `\"`)
- Precision formatting for floating-point numbers
